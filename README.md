# astrbot_plugin_osugreek

在图片中央贴上神秘的 4K 希腊字母，顺便加点色散和故障效果 —— 批量生产 osu!mania 练习图背景。

本插件移植自 NoneBot2 插件 [nonebot-plugin-osugreek](https://github.com/YakumoZn/nonebot-plugin-osugreek)（MIT），图像处理逻辑与原版一致，只重写了 AstrBot 的入口层。

## 安装

把整个 `astrbot_plugin_osugreek` 目录放进 AstrBot 的 `data/plugins/` 下，然后在 WebUI 插件管理里重载/启用即可。

依赖只有 Pillow（`requirements.txt` 已列出，AstrBot 环境通常自带）。

## 使用

```
/osugreek <希腊字母名称> [缩放] [色散强度] [故障强度] [gif]
/希腊字母 <希腊字母名称> [缩放] [色散强度] [故障强度] [gif]
```

两种发图方式：

1. 图片和指令发在**同一条消息**里（图片 + `/osugreek alpha`）；
2. 先**引用**一张图片，再发 `/osugreek alpha`。

参数：

| 参数 | 范围 | 默认 | 说明 |
|---|---|---|---|
| 希腊字母名称 | 见下方列表 | 必填 | 不区分大小写；填 `help` 或不填会回帮助 |
| 缩放 | 0.1 - 3.0 | 配置项 1.0 | 字母大小系数，紧跟字母名；1.0 为默认大小，调大时透明边距被裁、字母本体不被裁 |
| 色散强度 | 1 - 20 | 配置项 4 | RGB 通道分离程度，越大色边越明显 |
| 故障强度 | 0 - 5 | 配置项 0 | 0 关闭；越高越多错位/噪点/扫描线/模糊 |
| gif | `gif` / `动图` | 不填 | 静态图也生成故障循环动图，写在任意位置都能识别 |

示例：

```
/osugreek alpha
/osugreek alpha 0.6            缩小到 0.6 倍
/osugreek alpha 2              放大到 2 倍
/osugreek alpha 1 10
/希腊字母 beta 1 4 3
/osugreek alpha 0.5 6 3 gif    生成动图并缩小字母
```

## 动图

两种情况都会输出 GIF：

1. **输入本身就是动图**（GIF 或其它多帧图片）：自动逐帧做色散、故障和字母叠加，输出 GIF，沿用原图的帧时长。不需要加 `gif` 参数。帧数超过 `gif_max_frames` 时会等间隔抽帧，并把每帧时长按抽帧步长放大，保持总时长不变。
2. **输入是静态图 + 第四个参数填 `gif`**：重复生成 `gif_frames` 帧，每帧重新随机一次故障效果，形成循环故障动画。这种情况故障强度为 0 时按 1 处理，否则每帧完全一样、看不出动画。

动图默认按 `gif_max_side`（800px）缩小、每帧 `gif_duration`（100ms）播放、无限循环，输出为 256 色 GIF。想更清晰可以调高这两个配置，但体积和上传耗时也会跟着涨。

注意：纯色或几乎没有纹理的图片在低故障强度下，各帧可能完全一样，GIF 会被合并成单帧（看起来就是静图）。想要明显的动画效果，故障强度建议填 2 以上。

## 效果说明

- **字母大小**：以原图短边的 1.8 倍 × 缩放系数为基准。字母素材本身有大片透明边距，所以缩放系数大于 1 时字母图会超出画布、只裁掉透明边距；字母本体（含阴影）在任何缩放系数下都不会被裁掉，放大到装不下时会自动收回。
- **透明背景**：输出保留原图的透明轮廓，透明区域始终透明，故障噪点/色散不会在透明区生成彩色噪点；色散偏移时会把透明像素的 RGB 补成不透明区域的平均色，避免边缘出现黑边/青边。
- **透明图输出**：静态图输出 PNG（带 alpha 通道）；生成的 GIF 也保留透明区域（GIF 只支持 1 位透明，alpha < 128 的像素按完全透明处理），透明底的动态表情不会变成黑底方块。

## 配置项

在 AstrBot 插件管理页的配置面板里修改：

- `chromatic_intensity`（默认 4）：默认色散强度，1-20。
- `glitch_intensity`（默认 0）：默认故障强度，0-5。
- `letter_scale`（默认 1.0）：默认希腊字母缩放系数，0.1-3.0。
- `max_input_side`（默认 4096）：输入图长边上限，超过先等比缩小，防止超大图占满内存；0 表示不限制。
- `gif_frames`（默认 12）：静态图生成动图时的帧数（2-30）。
- `gif_duration`（默认 100）：动图每帧毫秒数（20-500）。
- `gif_max_side`（默认 800）：动图长边上限（100-2000）。
- `gif_max_frames`（默认 24）：输入动图最多处理帧数（2-60），超出等间隔抽帧。

指令里显式写了强度就以指令为准，没写才用配置项。

## 缓存

生成结果保存在 `data/plugin_data/astrbot_plugin_osugreek/cache/`，保留 1 小时，之后在下次调用时自动清理。

## 移植说明

- 指令注册：`on_command` → `@filter.command("osugreek", alias={"希腊字母"})`。
- 取图：原版自己调 `get_msg` 拉引用消息，AstrBot 的 aiocqhttp 适配器已经会把被引用消息展开成 `Reply(chain=[...])`，所以直接遍历消息链即可。
- 图片来源：`Image.convert_to_file_path()` 统一处理 base64 / http / 本地路径。
- 配置：`.env` → `_conf_schema.json`。
- 发送：本地 PNG 路径交给 `event.image_result()`，由适配器转 base64 发出。
- 图像处理抽到 `greek_ops.py`，不依赖 AstrBot，可离线单测。
- 动图支持是在原插件（只处理单帧）基础上新增的：输入多帧图片逐帧处理，静态图可生成故障循环动画。
